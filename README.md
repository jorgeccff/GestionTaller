# GestionTaller

Aplicación de gestión desarrollada en Java como proyecto académico durante el ciclo de Desarrollo de Aplicaciones Multiplataforma (DAM).

## Descripción

Proyecto orientado a practicar el desarrollo de aplicaciones de gestión utilizando Java y programación orientada a objetos.

El proyecto trabaja con una estructura organizada de código y diferentes componentes para gestionar la lógica de la aplicación.

## Tecnologías

* Java
* Programación orientada a objetos (POO)
* IntelliJ IDEA
* Git
* GitHub

## Objetivo

Practicar conceptos fundamentales del desarrollo de software con Java, incluyendo organización del código, clases, métodos y desarrollo de lógica de aplicación.

## Contexto

Proyecto académico desarrollado durante la formación en Desarrollo de Aplicaciones Multiplataforma.
